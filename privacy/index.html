1. Principio local-first

Metatrón está pensada para guardar tus datos principalmente en tu dispositivo Android. No necesitas una cuenta Metatrón. No hay un servidor central obligatorio de Nancrow para usar notas, tareas, eventos, diario, hilos, hashtags ni hábitos.

2. Datos que se almacenan en el dispositivo

Según lo que escribas o configures, la app puede guardar localmente:

  • Notas, tareas, eventos, diario e hilos (títulos, textos, fechas, estados).
  • Hashtags y etiquetas que uses en el contenido.
  • Hábitos, frecuencia, recordatorios, completions, historial y comentarios asociados.
  • Borradores, preferencias de apariencia, onboarding, fondos personalizados.
  • Adjuntos: fotografías, vídeos y grabaciones de voz/audio que añadas.
  • Otras configuraciones necesarias para el funcionamiento (tema, programas instalados, etc.).

Los campos de texto libre pueden contener información personal que tú decides introducir. Metatrón no revisa ni clasifica automáticamente ese contenido.

3. Cámara, micrófono y archivos multimedia

  • Cámara: para tomar imágenes que quieras adjuntar a tus notas u otros registros.
  • Micrófono: para notas o grabaciones de voz que tú inicies.
  • Selector de medios / permisos de lectura de medios: para elegir fotos, vídeos o audio ya existentes en el dispositivo.

Estos accesos se usan cuando tú interactúas con esas funciones. No afirmamos un acceso continuo en segundo plano a cámara o micrófono. El procesamiento de adjuntos es principalmente local.

4. Hábitos

Si usas hábitos, se guardan en el dispositivo datos como título, frecuencia, recordatorios, completions e historial. Metatrón no trata esos datos como «datos médicos» ni como historia clínica.

5. Notificaciones

Puedes recibir recordatorios locales (por ejemplo, de hábitos) o avisos del servidor web local cuando está activo. No usamos notificaciones para publicidad ni para seguimiento publicitario.

6. Servidor web local (LAN)

Puedes activar, de forma opcional, un servidor web en tu teléfono para administrar tus datos desde otro dispositivo en la misma red local (por ejemplo, un PC en el mismo Wi‑Fi).

  • Es una función opt-in: solo funciona si la activas.
  • El teléfono actúa como servidor; no se envían tus notas a un servidor central de Nancrow.
  • El acceso está protegido con un token que puedes rotar.
  • Las conexiones se cifran mediante HTTPS/TLS. El certificado es generado en tu instalación (autofirmado); el navegador puede pedirte confirmarlo. En la app puedes ver la huella SHA-256 para compararla.
  • El token autentica; HTTPS protege el transporte. Son mecanismos distintos.
  • Los datos se envían únicamente al cliente de tu red que se conecte con el token correcto.

No uses el servidor LAN en redes públicas o no confiables. Quien esté en tu red y conozca la URL, acepte el certificado y obtenga el token podría acceder a tus datos locales.

7. Compartir y exportar

  • Al compartir con el sistema Android, el contenido va a la app que tú elijas; el tratamiento posterior depende de esa app.
  • Las copias de seguridad manuales o programadas que generes (por ejemplo ZIP) pueden incluir base de datos, preferencias y adjuntos. Quedan donde tú las guardes (almacenamiento del dispositivo, carpeta elegida, etc.).

8. Copia de seguridad de Android

La app permite el respaldo del sistema Android (allowBackup). Según la configuración de tu dispositivo y cuenta Google, Android puede respaldar parte de los datos de la app. Excluimos de ese respaldo automático secretos cifrados y el material privado TLS del servidor LAN. Las copias ZIP que tú exportas desde Metatrón no se ven afectadas por esas exclusiones.

9. Servicios externos y lo que no usamos

En la versión pública (perfil de tienda) no integramos publicidad ni analítica de terceros. En concreto, no están presentes Firebase Analytics, Google Analytics, Firebase Crashlytics, anuncios, AppsFlyer, Adjust, Sentry ni Advertising ID con fines de seguimiento.

En el código de desarrollo existen módulos experimentales (por ejemplo Google Calendar/OAuth, búsqueda de personajes, sync remoto o conectores HTTP) que no están disponibles en la superficie pública de Google Play. No forman parte del producto que el usuario de tienda puede activar.

10. Datos y permisos que no usamos en la versión pública

La versión auditada para tienda no utiliza ubicación, agenda de contactos del dispositivo (permiso persistente), permisos de calendario de Android, Bluetooth, Nearby ni Advertising ID para tracking.

11. Seguridad

Los datos viven en el sandbox de Android. Usamos almacenamiento local y, para ciertos secretos (por ejemplo tokens), almacenamiento cifrado cuando aplica. El servidor LAN usa HTTPS/TLS y token. Ninguna medida es absoluta: protege tu dispositivo, tu red y tus exportaciones.

12. Retención

Los datos permanecen en el dispositivo mientras existan en la app, no los elimines, no borres el almacenamiento de la app / no desinstales, o mientras existan copias externas que hayas creado. Si la app ofrece papelera o archivado, esos elementos siguen en el dispositivo hasta que los borres definitivamente o limpies datos.

13. Eliminación

No hay una cuenta Metatrón en la nube que borrar. Puedes:

  • Eliminar o vaciar contenido desde la propia app.
  • Borrar el almacenamiento de la app en Ajustes de Android.
  • Desinstalar la aplicación.
  • Eliminar backups o exportaciones desde la ubicación donde las guardaste.

Para preguntas: fernando.rdz.prianti@gmail.com.

14. Menores

Metatrón es una app general de productividad. No está diseñada específicamente para recopilar datos de menores. No usamos publicidad ni perfilado infantil.

15. Cambios

Esta política puede actualizarse. Publicaremos la versión vigente en esta misma dirección web. La fecha al inicio indica la versión actual del documento.
